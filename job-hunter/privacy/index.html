Política de privacidade do Job Hunter

Vigência: 24 de setembro de 2026

O Job Hunter é um aplicativo de desktop da Probox Studio Technologies Ltda. Ele roda no computador de quem o instala. Esta página descreve como o app acessa, usa, guarda e compartilha dados da conta Google.

Quem é responsável

Probox Studio Technologies Ltda., Curitiba, Paraná, Brasil. Contato: paulo.e.r.moraes@gmail.com.

Dados do Google que o app acessa

Com a sua autorização, o Job Hunter usa estes escopos:

  • https://www.googleapis.com/auth/gmail.readonly, para ler mensagens da caixa de entrada.
  • https://www.googleapis.com/auth/gmail.send, para enviar e-mail pela conta conectada.

Na leitura, o app busca alertas de vaga e mensagens sobre candidaturas já feitas (confirmação, contato, recusa, vaga encerrada ou proposta). Ele usa remetente, assunto, data e o trecho necessário para identificar a vaga ou o desfecho. O endereço da conta conectada é lido para saber para onde enviar o relatório.

No envio, o app manda o relatório da varredura somente para a própria conta Gmail conectada. Ele não escreve para recrutadores nem para outras pessoas por esse escopo.

Para que os dados são usados

Os dados servem para montar a lista de vagas, comparar a vaga com o perfil profissional guardado no computador, atualizar o status de uma candidatura e mostrar o resultado na interface do app. O uso fica limitado a essas funções.

O Job Hunter não usa dados do Gmail para publicidade, crédito, revenda ou treinamento de modelo próprio. Não há leitura humana desses dados por um serviço da Probox: o processamento ocorre na sua máquina e nos provedores de IA que você mesmo habilita, descritos abaixo.

Onde os dados ficam

O token OAuth e o banco local (vagas, resultados e histórico) ficam em arquivos no seu Mac, na pasta de dados do app. A Probox Studio não opera um servidor que receba o conteúdo da sua caixa de entrada.

Os dados permanecem enquanto você mantiver o app instalado e a conta conectada. Apagar a pasta de dados local, ou revogar o acesso do Job Hunter na conta Google, encerra o uso desse token. Cópias já gravadas no disco só saem quando você apaga esses arquivos.

Com quem os dados são compartilhados

Trechos das mensagens relevantes, junto com as vagas em aberto no app, podem ser enviados à IA configurada por você: Codex, autenticado na sua conta ChatGPT, ou Antigravity (Gemini), autenticado na sua conta Google. O envio ocorre só para avaliar a vaga ou associar um e-mail de desfecho a uma candidatura existente.

Se você conectar o Trello, o app grava no seu quadro título, empresa, link e status derivados dessas mensagens.

Fora isso, a Probox Studio não vende e não transfere o conteúdo do Gmail a outros terceiros.

Política de dados do usuário do Google

O uso e a transferência, para qualquer outro app, das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

Como revogar o acesso

Você pode desconectar o Job Hunter em myaccount.google.com/permissions. Também pode remover o token na pasta de dados do app.

Alterações

Se o uso dos dados do Google mudar, esta página é atualizada e a data de vigência muda junto. A mesma URL permanece ligada na tela de consentimento e na página do Job Hunter.
